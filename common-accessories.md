## 3 Axis Probes:

Both the V6 style probes and Makera Wired 3 axis probe work on all of the machines. There is a hardware guide [here](firmware/supported-commands/mcodes/probing/3d-probe-support.md).

The stylus tip at the end of the probe is a hardware fuse and designed to bend before damaging the internals of the probe. For replacement the V6 probes use a M2.5 thread and the makera probe uses a M2 thread

## Spare Collets - 3rd party

The carvera machines use a DGZ-60E TL60C spindle and accept any 3rd party collets that fit that spindle. This means you can get up to 8mm diameter collets. \
\
A 3 slit collet has slightly higher holding force against rotating in the collet than a 4 slit as there is more material in contact with the bit. Relatively negligible at this scale and you will most likely overpower the motor before collet holding strength

The 4 slit has a very slightly higher clamping range, negligible at this size and you should only be using exact measurements

4 slit collets are easier to make

All told, it will make a much bigger difference if you get a higher quality instance of the either collet type, and with ali / ebay / etc you don't really get to choose your binning. A burr on the collet or missed chamfer will also completely throw differences out the window so always inspect for damage before using any spindle collets\
So it doesn't really matter.

I have all 3 slot collets, but it shouldn't matter either way
